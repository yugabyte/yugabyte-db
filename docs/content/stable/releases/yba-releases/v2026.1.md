For an RSS feed of all release series, point your feed reader to the [RSS feed for releases](../index.xml).

## Before you upgrade

{{< warning title="Upgrade from v2025.2.6.0" >}}

If you're running v2025.2.6.0, you cannot upgrade to v2026.1.0.x or v2026.1.1.x. Upgrade to [v2026.1.2.0](#v2026.1.2.0).

{{< /warning >}}

Before upgrading, review the information in [Prepare to upgrade YugabyteDB Anywhere](/stable/yugabyte-platform/upgrade/prepare-to-upgrade/).

### Highlights

{{% highlight-card title="New YugabyteDB Anywhere experience" link="/stable/yugabyte-platform/yba-overview/#new-experience" maturity="ea" idea="285" %}}
A redesigned workflow for creating and managing universes, with many usability enhancements, including the following:

- Universe configuration wizard with **Guided** and **Expert** modes, so you can start from resilience requirements or take full control of replication factor and per-zone node counts.
- Ranked preferred regions and availability zones to pin tablet leaders and reduce latency.
- Add Read Replica wizard, then edit placement, hardware, and flags independently.
- Review of placement and hardware changes before you apply them, including smart resize versus migrating to new nodes.
- Centralized **Settings** tab for universe configuration (placement, hardware, security, database, telemetry, and more).

**To use:** Disabled by default. To enable for Super Admin, set the **Enable new Universe experience** Global Runtime Configuration option (config key `yb.ui.feature_flags.enable_new_universe_experience`) to true. To enable for all users, set the **Whether to enable new universe experience for all users** Global Runtime Configuration option (config key `yb.ui.enable_new_universe_experience_for_all_users`) to true. See [New experience](/stable/yugabyte-platform/yba-overview/#new-experience).
{{% /highlight-card %}}

{{% highlight-card title="Oracle Cloud Infrastructure provider" link="/stable/yugabyte-platform/configure-yugabyte-platform/oci/" maturity="ea" idea="2457" %}}
Deploy and manage YugabyteDB universes on Oracle Cloud Infrastructure (OCI). Create an OCI provider configuration, store universe backups in OCI Object Storage, and use OCI Vault for encryption at rest.

**To use:** Navigate to **Integrations > Infrastructure > Oracle Cloud Infrastructure**. See [Create cloud provider configuration](/stable/yugabyte-platform/configure-yugabyte-platform/oci/). For backups, see [Oracle Cloud Infrastructure](/stable/yugabyte-platform/back-up-restore-universes/configure-backup-storage/#oracle-cloud-infrastructure). For encryption at rest, see [Create a KMS configuration](/stable/yugabyte-platform/security/create-kms-config/oci-kms/).
{{% /highlight-card %}}

{{% highlight-card title="Perf Advisor Collector" link="/stable/yugabyte-platform/troubleshoot/universe-issues/#perf-advisor-collector" maturity="ea" idea="2563" %}}
Collect universe performance monitoring data to include in [support bundles](/stable/yugabyte-platform/troubleshoot/universe-issues/#use-support-bundles), which you can share with {{% support-platform %}} for anomaly detection and cluster load analysis. Starting in YugabyteDB Anywhere v2026.1.1.0, YBA installer automatically registers the collector service during installation, and you can enable collection for universes you specify.

**To use:** Disabled by default. Open the universe and click **Actions > More > Enable Perf Advisor Collector**. See [Perf Advisor Collector](/stable/yugabyte-platform/troubleshoot/universe-issues/#perf-advisor-collector).
{{% /highlight-card %}}

Upgrade production clusters with confidence using the new optional canary upgrade mode. YugabyteDB upgrades a single fault domain first — for example, all nodes in one availability zone — then pauses for monitoring before proceeding. If an issue is detected, the upgrade rolls back automatically, leaving the rest of the cluster untouched.

After a user's canary tests and monitoring phase pass, the upgrade continues across remaining fault domains. The result is a dramatically safer upgrade path for production deployments, with a built-in safety net that catches problems before they can affect your entire cluster.

**To use:** Disabled by default. Set the **Enable Canary Upgrade Universe** Runtime Configuration option (config key `yb.upgrade.enable_canary_upgrade`) to true.
