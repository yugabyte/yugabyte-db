### Database

![Add Cluster Wizard - Database](/images/yb-cloud/cloud-addcluster-database-norg.png)

Set the following options:

#### Connection Pooling

Select this option to enable [built-in YSQL connection pooling](../../../../additional-features/connection-manager-ysql/).

#### Enhanced Postgres Compatibility

Select this option to enable [Enhanced PostgreSQL Compatibility Mode](../../../../reference/configuration/postgresql-compatibility/).

#### Resource Governance

Select this option to enable [Resource Governance](../../../cloud-clusters/resource-governance/) (database v2026.1.0 or later only). 

This feature is [Early Access](/stable/releases/versioning/#early-access-ea); to try it, contact [Yugabyte Support](https://support.yugabyte.com/hc/en-us).
