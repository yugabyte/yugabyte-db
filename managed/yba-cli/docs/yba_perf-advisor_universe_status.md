## yba perf-advisor universe status

Show how a universe is registered with Perf Advisor

### Synopsis

Show the collection mode a universe is registered in, and its destination

```
yba perf-advisor universe status [flags]
```

### Examples

```
yba perf-advisor universe status --universe-name <universe>
```

### Options

```
      --universe-name string   [Required] Name of the universe.
  -h, --help                   help for status
```
